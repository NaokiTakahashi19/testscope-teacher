# Testscope 先生向けモック

基準：2026-09-11「先生向け画面仕様・機能仕様案」。デザインは同日作成の事業者用 `testscope-evaluation-mock` のテーマ・カード・ヘッダー・ナビゲーションを継承。

## 操作できる画面
- テスト選択：公開済み3回、数学の先生としてログイン済み。
- 分析サマリー：担当・学校・全体の比較、学習段階の分布、分類別比較。
- 生徒・問題：検索、段階・正誤・分類絞込、並べ替え、設問別/単元別表示。
- 生徒詳細：得点、所属確率、単元別結果、実際の正誤。
- 問題詳細：問題・正解・正答率・答案の該当箇所の再現例。
- 回ごとの変化：各回全体・共通生徒・特定生徒と複数回選択。
- AI相談：対象条件と相談時の対象を保持する回答例、自由入力、キャンセル。

## モックの範囲
個人行は架空の担当生徒のみ。学校・テスト全体は架空の公開集計。点数・段階・所属確率・OCR答案は見本であり、実推定や実画像ではない。数学の分類は既存事業者用モックの分類資料を再利用。
認証、公開更新・権限失効、AI/OCR/LRT計算、通信エラー再試行、MCPは未接続。段階の共通尺度は未検証として表示。会話はページ内メモリのみ。サンプルは再読込で初期化。

## 検証
TypeScript型チェック、production build、HTTP 200を確認。
全3回の採点合計100点、24問、ID一意性、正誤と点数の一致、学校別段階人数合計、所属確率合計100%を確認。
ブラウザでの操作・視覚テストは未実施。
